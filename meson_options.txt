# Native bash is a NON-DEFAULT-SAFE build: bash and its bundled readline and
# GNU termcap are GPLv3, and meson folds them into libish.a with link_whole, so
# an enabled build SHIPS them whether or not anything calls them. Removing the
# applet-table entry is not enough -- measured, 144 bash objects and 35 readline
# objects stay in the archive.
#
# The FSF holds bash's copyright and has had GPL software pulled from the App
# Store twice (GNU Go 2010, VLC 2011), on the grounds that the store's Usage
# Rules are "further restrictions" barred by GPL section 6. iSH-AOK's own
# LICENSE.IOS waives enforcement for iSH's copyright holders; it cannot waive
# anything for the FSF.
#
#   auto      (default) on when deps/bash is checked out -- today's behaviour
#   enabled   fail configure if the submodule is missing, rather than silently
#             producing a build without it
#   disabled  leave bash, readline and termcap out of the binary entirely
option('native_bash', type: 'feature', value: 'auto',
       description: 'Compile bash in as a native program (adds GPLv3 code to the binary)')

# zsh as a native program. It began default-disabled, for one milestone
# question -- does ZLE, zsh's own line editor, work against AOK's terminal seam
# -- and since that was answered it has been ON, which is what `enabled' below
# says. The option remains so a build can leave zsh out deliberately.
#
# Licensing is not a constraint here, unlike native_bash: zsh's licence is
# permissive (MIT-like, see deps/zsh/LICENCE) and no GPL code is compiled in.
# Three GPLv2 files exist in the tree (Completion/Linux/Command/_qdbus,
# Completion/openSUSE/Command/_osc, Completion/openSUSE/Command/_zypper); they
# are completion SCRIPTS, data rather than code, and nothing compiles or
# installs them here.
#
# deps/zsh IS a submodule now, carrying a configured tree, so this is plainly
# `enabled' rather than `auto'.
option('native_zsh', type: 'feature', value: 'enabled',
       description: 'Compile zsh in as a native program (on by default; disable to leave zsh out)')
